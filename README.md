# CampusFlow Web API

A modular .NET 10.0 monolithic-to-modular refactored application designed with strict separation of concerns, zero circular dependencies, and a clean 11-project architecture.

## Quick Start
1. Clone the repository.
2. Open the solution: `CampusFlow.slnx`
3. Run the API:
   ```bash
   dotnet run --project src/CampusFlow.WebAPI
